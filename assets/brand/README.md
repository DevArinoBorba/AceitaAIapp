# Aceita AI — marca preta e prata

`aceita-mark.png`: símbolo com transparência, reconstruído com ImageGen a partir
da montagem de referência fornecida pelo usuário. Não é o arquivo vetorial
original nem uma extração pixel a pixel.

Instrução da extração: isolar o A metálico com estrada e selo de confirmação,
preservar a silhueta e as cores prata, retirar nome, slogan e fundo; entregar
somente o símbolo centralizado em PNG transparente.

O PNG é usado no cabeçalho Flutter. Os recursos Android incluem launcher legado
em cinco densidades, foreground transparente em 432 px, fundo preto e adaptive
icon (API 26+). A arte conserva margens para os diferentes recortes de launcher.
A tela de abertura do Android 12+ usa o mesmo foreground.
